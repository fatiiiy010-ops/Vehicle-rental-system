# Vehicle Rental System

A simple Python OOP project for managing vehicle rentals.

## Features

- Display available vehicles
- Rent a vehicle
- Return a vehicle
- Calculate rental cost
- Check vehicle availability
- Car and Bike classes
- Main menu for vehicle management

## Vehicle Types

### Car
- Vehicle ID
- Brand
- Rent per day
- Number of seats

### Bike
- Vehicle ID
- Brand
- Rent per day
- Engine CC

## OOP Concepts Used

- Classes & Objects
- Constructors
- Inheritance
- `super()`
- Method Overriding
- Polymorphism
- Encapsulation
- Instance Methods
